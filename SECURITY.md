# Security

Roster Mapper processes provider rosters, which hold personal information. It runs on your machine; the library sends nothing out, and the CLI's UI sends only NPIs and addresses to NPPES and the US Census geocoder for validation.

To report a vulnerability, use GitHub's private reporting: the **Security** tab of this repository → **Report a vulnerability**. Please don't open a public issue for it. We aim to respond within five business days.
